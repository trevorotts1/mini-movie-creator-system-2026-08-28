## 5. Data Contracts

### character.json (ai-shorts/<name>/character.json) — THE LOCKED CHARACTER REFERENCE

Example: `ai-shorts/blue-man/character.json`. Schema:

| Field | Purpose |
|---|---|
| `name`, `role`, `rule` | identity + the "never generate from text twice" doctrine |
| `image` | relative path to reference PNG (`character.png`) |
| `locked`, `approved_first_try` | human-eye lock date + approval flag |
| `video_model` | `{endpoint, picked_by, defaults{resolution, generate_audio, aspect_ratio}, cost_per_second_1080p_usd}` — the picked fal model + derived cost |
| `design` | body/head/accessory descriptions + sampled `palette` hex values |
| `generation` | the original prompt, model (`gemini-3-pro-image`), aspect, size, seed, created |
| `shot_workflow` | 3-step recipe: gen_image --ref → image-to-video → start==end frame pinning |

blue-man's picked model: `fal-ai/bytedance/seedance/v1.5/pro/image-to-video`, $0.0583/s at 1080p audio-off.

### beats.json (one per project, `shorts/short-N-*/beats.json`, `ai-shorts/*/beats.json`)

The machine contract consumed by the composition + tools. Schema (union of both track variants):

| Field | TSX shorts | AI shorts |
|---|---|---|
| `id`, `title`, `composition` | yes | yes (+ `subtype: "ai-video"`, `series`) |
| `format` | `{width:1080, height:1920, fps:30, durationSec}` | same |
| `voiceStatus` | `"elevenlabs:<voice_id>"` | same (different voice: George `JBFqnCBsd6RMkjVDRZzb`) |
| `vo[]` | per-line: `beat, text, start, end, words[{w,start,end}]` | + `tts` field with `[tag]` delivery cues |
| `beats[]` | timeline: `{id, start, end, visual}` | — |
| track-specific | `board` (chess: `hookFen`, `movesGlobalSec[{from,to,at,capture?,rewind?,restore?}]`) | `shots[]` `{n, slug, window_est, scene, seconds, file, start_frame, status, end_image_url_pin?}`, `costs_usd{...}` with derived-cost note |
| `notes` | — | workflow notes (loop constraint, wps estimates) |

Word-level timing (`words[]`) is written back by `tools/gen_voice.py` from real ElevenLabs
`/with-timestamps` output — captions highlight the exact spoken word.

### sfx-plan.json (one per project) — declarative cue sheet

Schema: `master` (voiced mp4), `master_fps`, `catalog` path, `render{preview, out, end_s, duck}`,
`events[]` = `{at_s, sfx_id, gain_db, shot?, cue, note?, optional?}`. Consumed by
`tools/mix_sfx.py` (`--print` = audit artifact; mix = sidechain duck + limiter). Hard USER-AUDIT
gate before mixing. Calibrated gain tables per track in the suggest-sfx skill.

### Other contracts

- `media/library/sfx/{catalog.json, palette.json, clips/*.mp3}` — 33 loudness-normalized clips
  (~−20 LUFS, −1.5 dBFS ceiling), each with source/license/used_in. Same shape for `music/` (6 clips).
- `media/library/logos/claude-code-bot.png` — the one logo.
- `vox-shorts/DESIGN.md` — the collage visual language (read before any vox work).
- `shorts/*/script.md` — human beat sheet: hook + table (time | on screen | VO) + notes.

## 6. Skills (`.claude/skills/`, 5 skills)

1. **make-short** — the 100%-TSX track. Beat grammar (HOOK composed at frame 0 → SETUP →
   optional QUIZ/PauseCard → REVEAL synced to VO words → TWIST → LOOP with last frame == frame 0,
   no CTA outros). Artifact contract (script.md/beats.json/voice//sfx-plan.json/output/ +
   `remotion/src/shots/short-N/`). Stage pipeline: script+beats → composition → **frame QA**
   (`npm run gen` then `node scripts/frames.mjs <Id> 0,<boundaries>,<last> --scale=0.5`, READ every
   PNG) → render scale 1 → ElevenLabs voice with `--emit-ts` word-exact captions → SFX → music.
   Rule of thumb: ~100 words VO at ~2.7 wps; at most ONE new niche lib per short.
2. **make-ai-short** — same backbone + 3 iron rules: (1) never generate the character from text
   twice (character.json + --ref image); (2) state derived cost BEFORE spending (token formula
   h×w×24×dur/1024 × $1.2/1M); (3) loop by CONSTRAINT — extract true frame 0 from clip 1, pass as
   `end_image_url` to the final shot, `LoopSettle` dissolve in composition. Order: script → voice
   FIRST → start frames (QA every PNG) → clips (state cost, parallel) → frame-by-frame clip QA →
   composition → SFX (gappy-VO −7..−8 dB calibration) → save back. `media/projects/<name>/` holds
   the COMMITTED clip copies (paid, non-reproducible pixels).
3. **make-vox** — collage track: scene dissection into 2–6 layers, layer production
   (gen_image → cutout.py rembg; HTML→PNG via capture_web.py; SVG arrows directly in TSX),
   `CollageBoard` camera keyframes + parallax, contrast rule (SerifStatement needs `backing`).
4. **vidtsx-2d-generator** — the TSX crash rules: frame-based only (no useState/useEffect/
   setTimeout/CSS animations), seededRandom at module level, strictly monotonic interpolate
   ranges, Easing.bezier, `<Img>` never `<img>`, compositionConfig skeleton, 6 style presets.
5. **suggest-sfx** — the SFX machinery: brand §7 taste contract, library-first sourcing,
   sfx-plan.json schema, USER-AUDIT gate, mix with ducking, RMS audibility verification
   (≥+4 dB story-critical), transient gain gotchas, SHORTS calibration table.

## 7. Frame-QA Approach (reusable core concept)

The QA discipline is: **never trust a reasoned render — dump specific frames and READ them.**

```
cd remotion && npm run gen                                    # registry must be regenerated first
node scripts/frames.mjs <CompId> 0,<beat-boundaries+hero-frames>,<last> --scale=0.5
# → out/qa/<id>-f<NNNN>.png   (phone-scale legibility)
```

Checklist from make-short Stage 3: frame 0 fully composed (no fade from black) · every reveal
synced to its beat · nothing covering the payoff element · kickers swap with narration · captions
clear of UI zones (safe areas: nothing critical bottom 340px / right 160px) · loop frame ≈ frame 0.
Only after frame QA: `node scripts/render-all.mjs <Id> --scale=1`. For AI clips: start/mid/end
strip per clip + final-clip last frame vs loop target side-by-side.

**The recurring bug it catches:** frames inside a `<Sequence>` are LOCAL —
`local_f = global_s * fps − sequence_from`.

## 12. Reusable Concepts Found (for MMCS build)

1. **beats.json contract** — one machine-readable file per video drives composition, captions,
   voice timing, SFX cues, and cost accounting. Word-level timing from real TTS (never estimate
   when a voice track exists).
2. **Locked-character doctrine** (character.json + reference PNG + `--ref` flag) — never
   regenerate a character from text; image-to-video from frames that already contain the character.
3. **Cost-before-spend gate** — derived token formula per model, stated before every AI call,
   ledgered in beats.json `costs_usd`.
4. **Loop-by-constraint** — frame 0 == last frame as a handed-to-the-model constraint
   (`end_image_url` pinning), not luck; `LoopSettle` composition pattern.
5. **Frame-QA discipline** — `frames.mjs` at phone scale, READ every PNG, specific checklists
   per track, before any full render. Catches real bugs every time (upstream's own claim).
6. **Registry generation** — `gen-registry.mjs` scans shots/ and auto-registers compositions;
   new TSX files drop in with zero wiring.
7. **Library-first media** — reusable SFX/music/image assets with catalogs + `used_in` tracking;
   per-video assets separate; reuse before generate.
8. **Declarative SFX plans** — sfx-plan.json + mix tool + RMS-numbers audibility verification +
   hard user-audit gate.
9. **Six-beat grammar** — HOOK (composed frame 0) → SETUP → QUIZ → REVEAL → TWIST → LOOP;
   no CTA outros ever; the loop-into-intro IS the ending.
10. **vidtsx hard rules** — frame-based animation only, monotonic interpolate ranges,
    Easing.bezier, seeded randomness at module level; the crash-prevention contract.
11. **Local-frame conversion discipline** — `local_f = global_s * fps − sequence_from`;
    the recurring upstream bug, named and checked.
12. **Three-track separation** — TSX / generative / collage with one shared backbone;
    skill picked from the request phrasing.
